# 🏋️ Health Fitness and Wellness Project

## 📌 Description
This project is a web-based application designed to help users track fitness, workouts, and overall wellness.

## 🚀 Features
- User login system
- Progress Tracking
- Diet planning
- Exercise Planning
- Dietician guidance
- Admin panel
- Health monitoring

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML, CSS
- XAMPP


## ⚙️ How to Run
1. Install XAMPP
2. Place project in htdocs folder
3. Start Apache & MySQL
4. Open in browser: localhost/project-name
